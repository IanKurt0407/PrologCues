# 🧠 NeuroCues: Sistema Experto de Análisis Cognitivo

![Python](https://img.shields.io/badge/Python-3.12-blue?style=for-the-badge&logo=python)
![Prolog](https://img.shields.io/badge/Prolog-SWI-red?style=for-the-badge&logo=prolog)
![Status](https://img.shields.io/badge/Estado-Prototipo-yellow?style=for-the-badge)

Un Sistema Experto desarrollado en **Python** y **Prolog** que utiliza inferencia lógica para identificar posibles patrones de neurodivergencia o neurotipicidad en base a un cuestionario interactivo.

> **⚠️ AVISO:** Este proyecto es puramente académico y demostrativo. No sustituye un diagnóstico médico profesional.

## 🛠️ Tecnologías
* **Python:** Interfaz de usuario y control de flujo.
* **SWI-Prolog:** Motor de inferencia lógica y base de conocimientos.
* **Librerías:** `pyswip`, `rich`, `pyfiglet`.

## 🚀 Instalación y Uso

### 1. Prerrequisitos
Debes tener instalado **SWI-Prolog** y agregarlo al PATH de tu sistema.
* [Descargar SWI-Prolog](https://www.swi-prolog.org/download/stable)
